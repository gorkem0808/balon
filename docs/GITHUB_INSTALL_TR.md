# GitHub Kurulumu

1. ZIP dosyasını bilgisayarda açın.
2. ZIP'in içindeki dosya ve klasörlerin tamamını GitHub deposunun ana dizinine yükleyin.
3. GitHub: **Settings → Pages**.
4. Source: **Deploy from a branch**.
5. Branch: **main**.
6. Folder: **/(root)**.
7. **Save**.
8. Yayın tamamlandıktan sonra **Visit site** ile açın.
9. Eski dosyalar önbellekte kalmışsa `Ctrl + F5` yapın.

Oyun arayüzü ve sesli mesajlar İngilizcedir.
