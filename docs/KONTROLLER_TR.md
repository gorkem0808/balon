# Klavye Kontrolleri

| Tuş | Görev |
|---|---|
| C | Kredi ekler ve kredi sesini çalar |
| SPACE | Kredi varsa oyunu başlatır |
| A | Sol sepet sensörünü simüle eder |
| L | Sağ sepet sensörünü simüle eder |
| P | Oyunu duraklatır/devam ettirir |
| F8 | Oyun ayarlarını açar/kapatır |
| F11 | Tam ekran açar/kapatır |

Yanlış taraftaki tuşa basılırsa puan verilmez ve yanlış sepet sesi çalar. Aktif balon doğru taraftaki tuşla patlatılır.
