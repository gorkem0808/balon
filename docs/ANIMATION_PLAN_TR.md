# Katmanlı Animasyon Planı

- Ana lunapark görüntüsü: sabit görsel tabanı.
- Dönme dolap: yavaş hareket eden ayrı görsel efekt katmanı.
- Bulutlar: sürekli yavaş loop.
- Lambalar: farklı fazlarda parlaklık animasyonu.
- Bayraklar: yumuşak sallanma.
- Dekor balonları: sepetlerin üzerinde değil, sahnenin kenarlarında hafif salınım.
- Panda/domuz: beklemede çok hafif ölçek/denge hareketi; ara sıra göz kırpma.
- Puan: yalnız doğru vuruşta kısa karakter kutlaması + güçlü konfeti.
- Yanlış sepet: kısa tepki; uzun/çılgın dans yok.
- Oyun balonu: sepet içerisinden büyük başlayıp yukarı çıkar.
