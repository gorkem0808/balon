# Ses Sistemi

Paket içindeki sesler `assets/audio/` klasöründedir.

- `music_loop.wav` — arka plan müziği
- `coin.wav` — kredi
- `start.wav` — oyun başlangıcı
- `launch.wav` — sepetten balon çıkışı
- `hit.wav` — doğru balon / puan
- `wrong.wav` — yanlış sepet veya kaçan balon
- `warning.wav` — oyun sonuna yaklaşırken uyarı
- `end.wav` — oyun bitişi

F8 menüsünde ana ses, müzik, efekt ve olay bazlı ses seviyeleri ayrı ayrı ayarlanabilir. Ayarlar tarayıcı `localStorage` alanında saklanır.
